# Pipeline, data format and commands

`E=$SKILL_DIR/engine` (`SKILL_DIR` = this skill's folder), `PY=~/.editorial-raea/venv/bin/python`. All scripts take the
project folder as the first argument. The engine files in the skill are read-only during project work: copy,
never edit them in place (prep.py copies edit.tsx into the project).

## Project layout

```
PROJECT/
  timeline.json          scenes, media, text layers           style.json        the look (from templates/)
  captions_config.json   approved corrections, accents        captions.json     word-timed captions (generated)
  sfx_config.json        SFX reels, cut points, title sounds  sfx.json          one event per transition (generated, editable)
  CREDITS.md             every source, licence, on-screen credit
  footage/               link to the source video             transcript/       words.json, assemblyai_raw.json
  assets/archive|generated|brand|sfx/                          cache/masks/      person masks NNNNN.png
  raea/                  edit.tsx + manifest.json + media/ (generated by prep.py; delete to rebuild)
  out/                   renders, audio mixes                 stills/           test stills
```

## Commands, in order

| Step | Command | Notes |
|---|---|---|
| New project | `$PY $E/init_project.py PROJECT --source FILE` | probes size, fps, frames |
| Transcript | `$PY $E/transcribe.py PROJECT --language id --keyterms "Name,Brand"` | prints low-confidence words to confirm |
| Captions | `$PY $E/build_captions.py PROJECT` | after the user approves `fix` |
| Masks | `$PY $E/make_masks.py PROJECT --engine local` or `--engine fal` | only for `behind: true` text; ask the user which engine (first-time-setup.md, Step 2b) |
| Prep | `$PY $E/prep.py PROJECT` | after every timeline/style change; skips unchanged media |
| Stills | `$PY $E/deliver.py PROJECT --stills 6.5,33,52 -o PROJECT/stills/vN` | look at every cut, entrance, split, mask |
| SFX library | bundled: `cp -R $SKILL_DIR/sfx/ PROJECT/assets/sfx/` (trailing slashes: copies the contents, not a nested folder) (24 cut clips + library.json), or `$PY $E/sfx_cut.py PROJECT` for new reels | set `titles` in sfx_config.json to the new text ids |
| SFX mix | `$PY $E/build_sfx.py PROJECT` (`--mix-only` after editing sfx.json) | writes `out/audio_sfx.wav` |
| Formats | `$PY $E/make_format.py PROJECT --aspect 9:16` (also `4:5`, `5:4`) | after the master is approved; then prep, stills, fixes and deliver on `PROJECT/formats/9x16` |
| Deliver | `$PY $E/deliver.py PROJECT -o PROJECT/out/edit_vN.mp4 [--audio PROJECT/out/audio_sfx.wav]` | raea master → x264 CRF 20 → checks |

Without `--audio`, deliver.py copies the source audio bit-exact. Run renders longer than ~2 minutes in the
background and wait for the notification.

## timeline.json

`templates/timeline.example.json` has one of each scene type. Times are programme seconds; programme time =
source time (the source is never re-cut).

**captions**: `"burn"` (default: drawn into the picture, plus an .srt next to the MP4), `"srt"` (only the .srt file next to the MP4), or `"none"`. Per scene, `cap: "off"` still hides captions where the screen text says the words.

**source**: `path` (relative to PROJECT), `width`, `height`, `fps`, `frames`, `presenter_center_x` (where the
presenter's body centre is, 0–1; splits re-centre them in their half), `baked_cuts` (cuts already in the footage,
seconds: never return from B-roll onto a stray frame of the other take).

**output** (optional): `{width, height}` makes the canvas differ from the source (set by make_format.py: 9:16 =
1080×1920, 4:5 = 1080×1350, 5:4 = 1350×1080). **reframe** (optional): `[[t, cx, cy, zoom], ...]` keys, linear between
keys: the source point (cx, cy) sits at the canvas centre, zoom ≥ 1 on top of "cover". Person masks follow the plate.
In portrait formats all text sizes are still px at 1440p on the canvas's short side (1080 px → ×0.75).

**media** `id: {kind: image|video, path, look: bw|color, trim?: [l,t,r,b], credit, source}`. prep.py grades `bw`
media (bright archival B&W, one exposure per clip) and blooms all media.

**scenes** (cover 0 → end with no gap; one active at a time):
- `presenter` — the source plate. `grain: "insert"` uses insert-strength grain (e.g. an opening).
- `full` — `media`, `src_t0` (seconds into a clip), `move: {from: [fx, fy, zoom], to: [...]}`, `cap: "ink"` on
  light pictures, `cap_x`.
- `montage` — `shots: [{media, t0, t1, move}]`.
- `collage` — paper ground; `items: [{media, rect: [x0,y0,x1,y1], focus, rot, push: [z0,z1], t0?, t1?}]`, torn
  edges and shadows; `lines: [{x0,y0,x1,y1,t0,t1}]` oxide rules that draw in.
- `split` — `side: left|right` (panel side), `at: 0.5`, `entry`, `exit` (slide in/out, only next to the presenter),
  `inserts: [{media, t0, t1, focus, push, src_t0?}]`. Two splits in a row: `exit: false` then `entry: false`.
- Any scene: `cap: "ink" | "off"` (captions dark, or none when the screen text already says the words).

Sizes are px **at 1440p** (`style.json` `ref_height`): the engine scales every size, caption, grain and shadow to the source height, so the same timeline values work at 1080p, 1440p and 2160p.

**text** layers: `id`, `font` (sans, sans_medium, sans_light, serif, serif_it, mono), `size` (px at source size),
`tracking` (em), `text` (`*word*` = Didot italic accent), `x`, `y` (baseline, 0–1 of the frame or of the split
panel when `panel` is set), `anchor` (ls, ms, rs), `color` (ink, cream), `t0`, `t1`, and optional:
`words: [t...]` one reveal time per word (from the transcript; separator tokens such as `·`, `/`, `&` take no slot and appear with the word before them), `step: true` stop-motion entrance at 12 fps,
`card: true` torn paper label, `shadow: true` (cream on photos), `behind: true` (behind the presenter: needs masks),
`panel: SCENE_ID`, `enter: "cut"`, `exit: "cut"` (hard swap instead of the soft exit).

## Revisions

- Keep every version: `out/edit_v2.mp4` beside `out/edit_v1.mp4`, never over it.
- Variants: copy `timeline.json` to `timeline_A.json` etc. in a copy of the project folder (or keep variant
  files and swap them in), run prep + stills for each, show the stills, apply the chosen one.
- After a picture-only change with the same duration, keep the approved audio (`--audio` the same mix file).
- A full raea render is fast, so render the whole film again instead of splicing parts.

## raea notes

raea draws each frame from React (edit.tsx). Python bakes what CSS can't do exactly: the B&W curve, bloom, torn
masks, paper, grain fields and person masks. Measured against the reference CPU renderer on a 2560×1440 60 fps
edit: same layout and grade, grain within ~20 %, about 6× faster (a full 105 s, 6,333-frame 1440p60 edit renders
in about 4 minutes on an M5). raea's MP4 writer stops at 4 GB, so deliver.py renders the master at the highest
bitrate that fits (≤ 250 Mbit/s) and deletes it after the x264 encode. Keep about 10 GB free per minute of
1440p60 while a render runs. raea's own `raea check` targets -14 LUFS for
platform mixes; this skill keeps the speech's original level, so ignore that one finding.
