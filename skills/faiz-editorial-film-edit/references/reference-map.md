## How to achieve the intended combination

The four external videos supply techniques; the four photographs supply texture and materiality. [style-guide.md](style-guide.md) defines how to combine them: soft optics, light temporal grain, bright neutral B&W, three font roles, selective stepped text motion, real masks and a restrained split used only with a presenter. Do not copy other people's phrases, people, exact timelines or number of inserts. For a non-technology topic, find archival materials appropriate to it.

Start with the frame overviews. Use the MP4s and dense frame sequences to assess pacing and smoothness. If the environment cannot play motion, extract adjacent frames with a tool, preserving timestamps, and honestly state the limits of that check. An installed codec, the absence of decoding errors or a file listing does not mean the video has been visually reviewed.
